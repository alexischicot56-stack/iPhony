Chaque app publiée reçoit automatiquement l'objet iPhonyPhotos : aucune installation, aucune clé. Il donne accès (lecture seule) aux photos et vidéos prises avec l'Appareil photo, après autorisation de l'utilisateur.

Méthodes (toutes asynchrones)

status() → 'granted' | 'denied' | 'undetermined'
requestAccess() → affiche la demande d'accès, renvoie le statut
list({type, limit, offset, order}) → [{id, type, mime, width, height, duration, size, createdAt}]
  type : 'photo' | 'video' · order : 'desc' (défaut) | 'asc'
getBlob(id, {thumbnail}) → Blob
getURL(id, {thumbnail}) → URL utilisable dans img / video
openCamera() → ferme l'app et ouvre l'Appareil photo
onChange(cb) → cb({type:'added'|'deleted', item}) ; renvoie une fonction pour se désabonner

Exemple

if (await iPhonyPhotos.requestAccess() === 'granted') {
  const items = await iPhonyPhotos.list({ limit: 20 });
  for (const it of items) {
    const img = new Image();
    img.src = await iPhonyPhotos.getURL(it.id, { thumbnail: true });
    document.body.append(img);
  }
  iPhonyPhotos.onChange((e) => console.log(e.type, e.item));
}
